# SOP — Production / Design Studio

_How a placed order becomes a delivered, MLS-ready file. This is the crown-jewel process; treat every step as protecting the "one standard, 24–48h" promise._

- **Owner:** Studio lead / Head of production
- **Version:** 0.1 (draft) · **Last reviewed:** set on adoption · **Review:** quarterly
- **Applies to:** virtual staging, furniture removal, virtual renovation, 3D floor plans, 3D renders, day-to-dusk & photo edits, 360° tours.
- **Standards referenced:** Bella Quality Standard (Quality/Art-direction SOP), brand tokens, disclosure/AB 723 rules.

## SLA clock (targets)
| Service | Target turnaround | Clock starts when |
|---|---|---|
| Virtual staging / removal / edits | **24–48 h** | Usable photos + order are in hand |
| Floor plans / 3D renders | Per quote | Required blueprints/dimensions are in hand |
| Revisions | **≤ 24 h** per round | Revision request received |

> The clock starts only when we have what we need. If an order is missing files, it's **On hold — waiting on client**, not late (see §1). Ops owns the clock; Production owns the work.

---

## 1. Intake & validation _(owner: production coordinator)_
- [ ] Order received; confirm services, quantities, and any style brief.
- [ ] **Photos/files present and usable?** Empty-room shots for staging; blueprints/dimensions for floor plans & renders; 360° equirectangular for tours.
- [ ] Photo quality check: whole room in frame, level, enough floor visible, no heavy filters, no people/reflections. (Ref: virtual-staging photo guide.)
- [ ] Property address / file labels captured; match order to listing.
- [ ] **If anything is missing or unusable:** set **On hold — waiting on client**, send the request (the client can upload from their dashboard later), and *stop the SLA clock*. Do **not** start work.
- [ ] If complete: mark **In production**, start the clock, pass to assignment.

## 2. Assignment _(owner: production coordinator)_
- [ ] Route to a designer with the right specialty and available capacity (Fulfillment owns capacity).
- [ ] Attach the **style brief**: designer's-choice vs. a specified style / style-quiz result; room types; buyer/market notes; brand look.
- [ ] Confirm scope: photo count, add-ons (removal, reno, dusk), per-photo style selections.
- [ ] Log expected-ready time (well inside SLA).

## 3. Staging / production _(owner: designer)_
- [ ] Furnish/produce to the **Bella Quality Standard** and the style brief — real designer judgment, **never one-click AI**.
- [ ] Furniture removal first where applicable (included), then stage the cleared room.
- [ ] Match scale, perspective, light and shadow to the room so it reads real.
- [ ] **Disclosure-safe:** enhance, never misrepresent. Don't remove/add permanent features, don't alter what can't truthfully change. Keep it AB 723 / disclosure compliant.
- [ ] File hygiene: correct dimensions, color, naming `{address}-{room}-{service}`; highest resolution; **watermark-free** final.
- [ ] Self-check against §4 before submitting to QA.

## 4. Internal QA _(owner: art director / QA)_ — release gate
- [ ] Matches the brief (style, rooms, count) and the Quality Standard.
- [ ] Perspective/scale correct; furniture sits on the floor plane; shadows consistent.
- [ ] Clean edges, no artifacts, no warped lines; realistic, not "obviously staged."
- [ ] Disclosure-safe; no permanent features altered.
- [ ] Files: right format/resolution, named correctly, watermark-free, MLS-ready.
- [ ] **Pass →** release to delivery. **Fail →** back to designer with specific notes (this is normal; catch it here, not at the client).

## 5. Delivery _(owner: production coordinator)_
- [ ] Publish files to the client's **project dashboard**; notify client.
- [ ] Confirm everything ordered is present; include marketing kit if selected.
- [ ] Stop the SLA clock; log actual turnaround.
- [ ] Set status **Delivered — awaiting review**.

## 6. Revision loop _(owner: support → designer)_ — free & unlimited for 2 weeks
- [ ] Support logs the revision request against the order.
- [ ] Triage: quick tweak vs. a re-do; clarify with the client if ambiguous (pinned comments preferred).
- [ ] Assign back to the **original designer** where possible; target **≤ 24 h**.
- [ ] Re-run §4 QA on the revision before re-delivery.
- [ ] Repeat until the client approves. Log revisions/order (a spike is a QA or brief signal — feed it back to §2/§4).

## 7. Rework / refund escalation _(owner: support lead)_
- [ ] If the client is unhappy after reasonable revisions, escalate: rework by a senior designer **or** refund per the rework-or-refund guarantee.
- [ ] Record root cause (bad brief? missed QA? unusable input?) and fix the process, not just the order.

## Roles at a glance
- **Production coordinator** — intake, assignment, delivery, the queue.
- **Designer** — the staging/render itself, to standard and brief.
- **Art director / QA** — the release gate; owns the standard.
- **Support** — client comms and revision intake (hands work back to Production).
- **Fulfillment/Ops** — capacity and the SLA clock (external to this SOP; see Operating Model).

## Handoffs
- **In:** Sales/self-serve order → Intake (§1).
- **Out:** Delivered files → Support/Success; revisions loop back in at §6; Finance invoices/settles.

## Metrics this SOP is judged on
On-time delivery %, average turnaround, revisions per order, internal QA pass rate, escaped-defect (client-caught) rate, rework/refund rate.

## Common edge cases
- **Occupied / furnished room** → furniture removal first (included), then stage.
- **Missing blueprints for a render/floor plan** → On hold — waiting on client; don't start.
- **Rush / hard deadline** → flag to Fulfillment for capacity; confirm before promising.
- **Unusable photos** (dark, tight crop, ultra-wide, reflections) → request re-shoot; send the photo guide; hold the clock.
- **Style mismatch on review** → treat as a revision (§6), and check whether the §2 brief was thin.
